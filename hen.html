PS3HEN

Homebrew Enabler for non-CFW consoles.

The Alternative

HEN is a software exploit that runs homebrew and backups on Super Slims and late Slims that cannot install CFW.

Which Models?

Required for Super Slim (CECH-4xxx) and Slim CECH-30xx. Also needed for some CECH-25xx if firmware is 3.60+.

Not Permanent

HEN resets when you turn off the console. You must re-enable it each time using the browser exploit.

Installation

Install HFW 4.84.2+, copy HEN files to USB, install HENTAI.pkg, and launch the enabler from the XMB.
