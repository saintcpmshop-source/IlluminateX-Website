📥 How to Install on your PS3

  1. Click the Download .PKG button above.
  2. When the PS3 browser asks where to save the file, select Save to /dev_hdd0/tmp/ (or plug in a FAT32 USB and save it there).
  3. Once downloaded, exit the browser and go to the Game column on your XMB.
  4. Scroll down to Package Manager and press X.
  5. Select Install Package Files.
  6. Find IlluminateX.pkg in the list and press X to install it.
  7. Once installed, launch IlluminateX from the XMB!
⚠️ Note: Make sure your PS3 is running Evilnat CFW or PS3HEN before installing. If you haven't jailbroken your console yet, check our Model Checker.
