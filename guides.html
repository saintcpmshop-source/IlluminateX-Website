Installation & Guides

Everything you need to know.

📥 How to Install

1. Download the .pkg from the Download page.
2. Place on FAT32 USB or PS3 HDD.
3. Go to Package Manager.
4. Install and launch.

🌡️ Fan Speeds

Open Hardware tab. Select Manual Fan and set between 30%-80%.

🎮 Patch EBOOT

Place game folder on HDD. Open Game Mods tab and select Patch EBOOT.

📦 Merge Split PKGs

Place all parts in one folder. IlluminateX will merge them automatically.
